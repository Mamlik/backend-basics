# City summary. Погода по городу и курс валюты к рублю

## Требования

Python 3.12

## Установка окружения и зависимостей

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Пример запуска

```bash
python3.12 main.py --city Moscow
python3.12 main.py --city London --currency EUR
```
